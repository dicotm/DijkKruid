# DijkKruid website

## Producten, prijzen en foto's aanpassen
1. Open `beheer.html` in Chrome of Edge (dubbelklikken) en kies de map van de website.
2. Pas producten, prijzen en foto's aan en klik op **Opslaan**.
3. Dubbelklik op `deploy.bat` om de wijzigingen op de NAS te zetten.

Alle producten staan in `products.json`. `beheer.html` en `products.backup.json` blijven op je eigen computer
en worden niet geüpload.

## Bestanden voor de website
index.html, producten.html, privacy.html, shop.js, catalog.js, products.json en de mappen images en fonts.
(Voor GitHub Pages: upload deze bestanden zelf; deploy.bat is alleen voor de NAS.)
