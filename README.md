# DijkKruid

Responsive GitHub Pages website for DijkKruid, based on the supplied DijkKruid design.

## Publish on GitHub Pages

1. Put the contents of this folder in the root of the `dicotm/DijkKruid` repository.
2. In GitHub: **Settings → Pages**.
3. Select **Deploy from a branch**.
4. Select the `main` branch and `/ (root)`.
5. Save.

The site is static HTML/CSS/JS and works on phone, tablet/iPad and desktop.

## Assets

The `images/` folder contains the DijkKruid logo and the product photos supplied for this project.
